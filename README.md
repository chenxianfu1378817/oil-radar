# 国际原油观察站 · Crude Oil Radar

国际原油行情与地缘形势综合分析面板。

## 功能
- 布伦特 / WTI 主力合约最新价格与日内涨跌
- 近 90 个交易日双基准走势图（可交互悬停查看价差）
- 地缘与基本面因子面板（美伊冲突、霍尔木兹、OPEC+、库存、美元、运费）
- 情景推演（四情景概率与价格区间）
- 关键技术位与观察指标清单

## 数据来源
- 行情：新浪财经全球期货行情接口（日收盘价，主力连续合约）
- 分析要素：公开财经媒体与机构研报信息聚合

## 更新方式
`data.js` 由抓取脚本生成。重新抓取最新数据后提交即可刷新页面。
